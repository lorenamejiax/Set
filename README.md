# Set

Set is a beginner-friendly single-page nail inspiration app. It gives users a clean Pinterest-style gallery for browsing nail designs, saving favorites to themed boards, and building a custom collage to show their nail tech.

## Features

- Gallery homepage with image-first cards
- Filters for color, shape, and length
- Preview modal with tags and save actions
- Save nail designs into named boards
- Persist boards with `localStorage`
- Custom Set prototype generator with Clean, Glam, and Experimental options
- Show My Tech collage builder with notes for your nail tech

## Run locally

1. Open a terminal in the project directory.
2. Start a local server:

```bash
python3 -m http.server 8000
```

3. Open your browser at:

```text
http://localhost:8000
```
